# History by Ear

Dr Edmund Thornleigh's spoken history of mankind, built for VoiceOver and hands-free listening.
Dr Thornleigh is a fictional Victorian historian. His essays were written for this app.
The readings in t/wp-*.json are adapted for listening from Wikipedia articles and are shared under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/); see Credits in the app for each article and revision.
